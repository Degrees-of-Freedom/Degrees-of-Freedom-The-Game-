# Degrees of Freedom: The Game

Degrees of Freedom is a turn-based structural engineering game where players build and test structures on a 3D grid. Each decision changes how forces travel through the structure—and whether it can stand.

## Core concept

Players take turns placing structural members and connections, applying loads, and developing a structure over time. The goal is to make deliberate choices about support, stability, strength, and efficiency while responding to the challenges of each game mode.

The game aims to make structural behavior visible and understandable. Players can explore how a change in geometry, connection, support, or load affects the whole structure.

## Game modes

- **Goal-based:** Build a structure that meets a challenge, such as carrying a specified load or reaching a target location.
- **Failure-based:** Continue building and loading a structure until it becomes unstable or a member fails.

These are starting concepts; rules, scoring, and additional modes can evolve as the game develops.

## Structural feedback

The game is intended to evaluate and communicate:

- **Load paths:** How forces travel through members and connections toward supports.
- **Instability:** Whether the structure can move as a mechanism or lacks adequate restraint.
- **Failure:** Where members or connections exceed their limits under load.
- **Complexity:** How the size and arrangement of the structure affect a solution, potentially measured through member count, connections, or material used.

## Project status

The project is in the concept stage. Gameplay rules, analysis methods, visual presentation, and technical implementation are still to be developed.
