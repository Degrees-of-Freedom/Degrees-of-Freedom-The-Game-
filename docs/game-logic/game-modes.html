Two measurements behind every score

Load on a foundation: the downward reaction there after a solve. In a stable structure the reactions add up to the applied load, so with several foundations it is a share of 100%, and with one foundation it needs a second quantity (material used) to mean anything.

Instabilities: parts that can move without resistance. Proposed count for now: nodes that move freely, which the voxel-struct prototype already reports. The shared solver contract on main does not return reactions or instabilities yet.

Questions to settle first

  1. Multiplayer: one shared structure or four separate ones? Proposed: shared, so every move changes everyone's share.
  2. How is an instability counted? Proposed: freely-moving nodes now, independent mechanisms later.
  3. Is a connection set per member end or per node? "1 member, 2 connections" points to per member end.
  4. Where do multiplayer loads come from? Proposed: the scenario, not the players.
  5. When does a multiplayer game end? Proposed: 8 rounds, score summed per round.
  6. Is load on a foundation vertical force only? Proposed: yes, downward only.
  7. Do member strength checks belong in these modes? This draft scores only load and instability.
