# Instability, Failure and Minimal Local Correction Criteria

## 1. Current policy and supersession

The [multiplayer refresh](multiplayer-refresh-criteria.md) replaces the earlier physical-scaffolding repair policy. Keep the player move and historical eligible penalty; establish success with the minimum supported **local constraint** intervention. **No columns straight down, props, scaffold members, extra foundations or ground-anchor meshes.** The only foundation per player is their immutable default starting one.

These are criteria, not implemented success guarantees. A solver verifies an explicit corrected idealized model; it cannot find a stable equilibrium for every arbitrary unaltered mechanism by changing presentation. Invalid player drafts remain invalid; the auto-fixer must not covertly change card legality, erase loads or relocate pieces.

## 2. Allowed correction set

Start with diagnosed local rotational freedoms and add only the minimum required restraint components at the affected joint/element interfaces. Avoid locking all rotations/all joints by default. Prefer explicit relative rotational coupling where it can work; declare the actual reference of each corrective constraint. Do not silently claim a world restraint is merely a relative connector law.

If rotational actions are insufficient, the owner permits minimum **system-only local translational safety restraints when required**. This is a recorded gameplay idealization, not a drawable translational connector or new physical foundation. Store its target/reference frame, constrained components, exact/effective law, origin issue/turn/checkpoint and reaction. Show this as a **game safety restraint**, not a real downward column or the original unmodified equilibrium.

Player original connection masks, capacities and geometry remain immutable. System corrections are separate layers with neutral ownership and explicit effective constraints. No hidden huge-stiffness spring, arbitrary section upgrade, ignored force or load deletion. If a broader local reinforcement action is later wanted, it requires its own authored rule and validation; do not quietly expand the repertoire.

Choose bounded deterministic candidates by diagnosed relevance, fewest added components and least local intervention, with stable tie-breaks. “Minimum” is a documented local objective, not a claim of solving global optimality. Keep placement/clash/quarter/setup rules intact. Correction lifetime remains permanent for the current match as previously confirmed, now as constraint records rather than added scaffold geometry.

## 3. Scheduled detection and original-turn penalty

Do not run the fixer/structural solver after every live placement or turn. Default checkpoint is every three globally completed player turns, interval editable, plus match end. At a checkpoint replay the pending turns, assess before correction and attribute one eligible -1 to each responsible original turn/player. Replay is internal checkpoint work, not a cadence bypass during live turns.

Use verified compatible baseline/evidence and stable issue/component lineage. Classify new, persistent, worsened, resolved and unknown; no repeated deduction for unchanged issues, jitter, mode-basis changes or retries. No physical penalty from an illegal target, numerical timeout or unknown prior scope. Multiple affected objects on one original turn still produce at most one deduction. Historical penalties remain after correction.

Record original live state and retrospective corrected replay lineage. Intermediate replay corrections cannot delete/relocate later player moves. If a compatible replay/correction cannot be verified, preserve the unresolved scope without blaming the checkpoint player or inventing an earlier cause. Deduplicate all repair/penalty events across retry, quit and reload.

## 4. Verification, reactions and explanation

Reanalyze the corrected model for stability, all supported member/connection capacities, active cable laws, compatibility and equilibrium. A local edit may redistribute forces globally; report those real consequences and reject candidates that create unhandled issues elsewhere. Do not confuse a successful factorization with capacity success.

Safety-restraint reactions participate in the corrected-model force/moment balance and earn no player attraction. Keep them distinct from original foundation reactions and from unavailable results; total applied gravity remains the scoring denominator. A verified corrected model is not proof the uncorrected player structure was independently stable. Final fallback scores only verified player reactions and leaves unknown physical quantities unavailable.

Timburr identifies what went wrong, the responsible original turn, the local added restraint and its neutral reaction/scoring consequence. “A local rotational safety restraint was added here” replaces a column-to-ground animation. The inspector/results/history expose the same information without avatar/audio. Resolved active warnings clear, while original evidence and penalty stay in history. Unknown correction says pending/could not verify, not success.

## 5. Acceptance and remaining parameters

Required fixtures: isolated rotational mechanism corrected minimally; translation correction used only when rotation alone is insufficient; overload checked after correction; no vertical column/new foundation; no all-node six-axis clamp; exact reaction accounting without player credit; multiple responsible turns per checkpoint; unchanged issue; unresolved replay; final/due deduplication; permanence and no duplicate penalty/constraint after quit/reload. Target all ordinary supported legal game states with tested bounded correction, while retaining explicit fallback for unverified cases.

Remaining authored parameters: issue eligibility/severity/hysteresis, candidate/reference conventions, local search/analysis budgets, setup and quarter-law support. No freedom/fun goal permits fabricated equilibria or unstated card restrictions.

## 6. Automatic correction transaction

Freeze checkpoint/window/options → replay original moves → retain pre-correction evidence → attribute original-turn penalty → try minimum local constraints → verify complete affected model → atomically publish constraints/results/penalty lineage → show animated issue/correction/report → private next-turn handoff. On noncheckpoint turns skip the numerical stages and mark pending. On Quit suspend this exact phase and invalidate obsolete callbacks rather than force completion.

## 7. Permanent neutral repairs with local intervention

Historical links to this section now refer to **local safety-constraint records only**, not permission for scaffold geometry. Direct targets remain local to the flagged element/joint; no silent nonlocal edit. Corrections stay for the match unless a future rule changes lifetime. Their reactions are neutral/unscored and never create another foundation. Inspect original/effective DOFs and checkpoint provenance; whole-structure redistribution is not a violation of local edit scope.
