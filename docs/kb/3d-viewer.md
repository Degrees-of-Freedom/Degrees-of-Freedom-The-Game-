# 3D Viewer

The web scaffold uses Three.js to display a grid and axes, with orbit and zoom controls. It can draw lines for members whose endpoint nodes exist in the supplied model. Placement, selection, support and load visualization, and analysis feedback are not implemented.

The intended game aims to communicate load paths, instability, and failures. Coordinate conventions, accessibility, presentation, and interaction details remain open.
